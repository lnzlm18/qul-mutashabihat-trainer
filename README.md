# QUL Mutashabihat Trainer

A hifdh training tool built on the **Mutashabihat ul Quran** dataset from [Tarteel's Quranic Universal Library (QUL)](https://qul.tarteel.ai).

Mutashabihat are ayahs that share similar wording, structure, or meaning — the ones that commonly trip up memorisers because they look almost identical. QUL's dataset contains 5,277 of these entries.

## Three training modes

**Compare Mode** — See two similar ayahs side by side with their translations and the key differences highlighted.

**Quiz Mode** — An ayah appears and you guess which surah it belongs to. Scored with instant feedback and hints available.

**Spot the Difference** — Two similar ayahs shown together. Try to find what changed before revealing the answer.

## QUL Resources Used
